# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/a7b232e0-ca39-4c30-9e5f-875809373c23

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Formulário de orçamento

As solicitações são encaminhadas pelo serviço externo FormSubmit para `contato@kleberfrancisco.com`. No primeiro envio, confirme o endereço pelo e-mail de ativação enviado pelo FormSubmit. Os dados do formulário são processados por esse serviço.
